# 꽃 모델 v1: 박스 탐지와 개화 단계 분류

처음에는 `v11_flower`라는 이름이었고, 잎과 다른 모델이라 2026-11-03에 별도 저장소 `/helpai-storage/flower_git`의 `v1_box`로 옮겼습니다. 커밋 메시지와 `runs/`의 설정 파일에는 옛 경로가 남아 있습니다.

**상태: 판정과 v2 비교 완료, 쓸 모델 결정 전.** test와 val 라벨 보완 완료, train 95장은 사람 검토 전입니다. 잎 모델(v8, v9)과 분리해서 관리합니다. 가중치는 `runs/`에 있고 최종 모델이 정해지면 커밋합니다. 비교는 [`../v2_seg/COMPARE.md`](../v2_seg/COMPARE.md)를 봅니다.

## 구조
잎 파이프라인과 같은 2단계입니다.

1. **꽃 찾기:** YOLO 탐지, `flower` 1클래스
2. **단계 분류:** 박스 긴 변 × 1.25 정사각형 크롭 → 봉오리 / 개화중 / 만개

## 라벨 규칙
사용자가 2026-11-02에 확인한 기준입니다.

- **대상:** 사진 속 모든 꽃. 작은 봉오리, 초록 봉오리, 흰 꽃을 포함합니다.
- **박스:** 꽃받침까지 포함하고 줄기와 잎은 뺍니다. 가려진 꽃은 보이는 부분만 잡습니다. 꽃받침 포함이 더 정확한지는 학습 후 비교합니다.
- **봉오리:** 꽃잎이 닫혀 있음. 위에서 봐서 둥글게 보이는 초록 봉오리도 포함합니다.
- **개화중:** 꽃잎이 풀리기 시작함. 컵 모양이나 나선이 보이고 아직 납작하지 않습니다.
- **만개:** 꽃잎이 활짝 펴짐. 납작하거나 수술이 보입니다.
- **제외 영역:** 사진 가장자리에서 크게 잘린 꽃, 바닥에 떨어진 꽃, 흐리거나 가려져 판단이 어려운 대상
- **꽃자리:** 이 농장 사진에는 없습니다. 둥근 초록 대상은 봉오리로 표시합니다.
- **뺀 것:** 새순
- **뺀 사진:** 온실 전경(`20261030_135013.jpg`). 내부 카메라 시점과 달라 내보내지 않습니다.

## 분할
휴대폰 두 대가 같은 시각에 다른 재배대를 찍어서, 사진이 아니라 시각 구간 단위로 나눴습니다.

| 분할 | 구간 | 사진 |
|---|---|---:|
| test | 13:49:05~13:49:38, 13:50:07~13:50:52, 14:04:19~14:04:40 | 18 (전경 1장 제외) |
| val | 13:46:01~13:46:42 | 8 |
| buffer | test, val과 같은 재배대로 보이는 사진 (어떤 학습과 평가에도 쓰지 않음) | 9 |
| train | 나머지 | 108 |

- test 사진의 박스는 내보낼 때 test로만 가고 학습 데이터에 들어가지 않습니다.
- **화분 단위 분리는 아닙니다.** 같은 품종과 인접 재배대가 train에도 있습니다. 예를 들어 흰 꽃 `134851`, `134857`과 노란 꽃 `134337`, `134355`, `134757`입니다. 그래서 test 점수는 실제보다 높게 나올 수 있습니다.
- 사진은 모두 하루, 한 농장, 휴대폰으로 찍었습니다. 독립 평가는 다른 날 찍은 ESP32 사진이 필요합니다.

## 1차 학습 결과 (2026-11-03)
**최종 성능이 아닙니다.** 탐지는 train 13장으로 학습했고, 분류와 탐지를 연결한 평가는 아직 없습니다.

| 모델 | val | test 보완 전 | test 보완 후 |
|---|---|---|---|
| 분류: 정확도 / 매크로 F1 (라벨 박스 기준) | 0.899 / 0.785 | 0.888 / 0.764 | 0.905 / 0.780 (사진 단위 95% 구간 0.687~0.852) |
| 탐지: 정밀도 / 재현율 / F1 (사진 단위, 임계값 0.7, IoU 0.5) | 0.861 / 0.851 / 0.856 | 0.865 / 0.637 / 0.733 | 0.945 / 0.668 / 0.783 |
| 탐지: 같은 기준, IoU 0.3 | 0.901 / 0.891 / 0.896 | - | 0.973 / 0.687 / 0.805 |

- **임계값:** 0.7은 val에서 정했습니다. val 라벨은 아직 보완 전이라 다시 정해야 합니다. 참고로 test는 0.6에서 0.913 / 0.774 / 0.838입니다.
- **test 보완 전후 비교의 한계:** 추가한 봉오리 42개의 박스는 모델 예측이라 보완 후 점수에 유리합니다. 이 42개를 모두 빼도 임계값 0.7의 재현율은 0.639 이상입니다. 사람이 본 것은 임계값 0.6의 오탐과 미탐뿐이라, 맞게 잡힌 박스와 낮은 신뢰도 예측은 다시 보지 않았습니다.
- **탐지 약점:** test 재현율이 긴 변 80px 미만 0.50, 노란 꽃 구간 0.56, 사진 `135048` 23/64입니다.
- **분류 약점:** 개화중 정밀도가 0.415입니다. test에서 봉오리 32개를 개화중으로 판정했습니다.

## 탐지 모델 비교 (2026-11-03)
같은 라벨과 합치기 규칙으로 평가했습니다 (사진 단위, IoU 0.5, 임계값은 각 모델의 val F1 기준).

| 모델 | 학습 데이터 | 임계값 | val F1 | test 정밀도 | test 재현율 | test F1 |
|---|---|---:|---:|---:|---:|---:|
| `det/first` | train 13장 초안 | 0.65 | 0.937 | 0.945 | 0.734 | 0.827 |
| `det/second` | train 13장 보완 | 0.70 | 0.919 | 0.924 | 0.707 | 0.801 |
| `det/third_pseudo` | train 108장, 임시 라벨 3,380개 | 0.65 | 0.927 | 0.833 | 0.836 | 0.835 |
| `det/fourth_pseudo` | train 108장, `third_pseudo`의 임시 라벨 4,171개 | 0.55 | 0.906 | 0.736 | 0.790 | 0.762 |

- **임시 라벨:** `det/second`의 신뢰도 0.7 이상 예측입니다. 사람이 보지 않았고 라벨 원본에 넣지 않았습니다 (`48_pseudo_export.py`, `data_pseudo/`). 0.3~0.7 예측 2,814개는 회색으로 가렸습니다.
- **재현율 변화 (`first` → `third_pseudo`):** 긴 변 80px 미만 0.62 → 0.78, 노란 꽃 구간 0.645 → 0.80, 사진 `135048` 27/64 → 48/64
- **정밀도 비교의 한계:** test와 val에 추가한 라벨은 `first`의 예측 박스이고, `first`의 오탐만 사람이 봤습니다. 그래서 `first`에 유리하며, `third_pseudo`의 오탐에는 라벨이 빠진 꽃이 있을 수 있습니다. 오탐 87개 중 36개가 사진 `135052`에 몰려 있습니다.
- **`first`와 `second`:** 차이가 판정 가능한 수준이 아닙니다. 위 한계 때문에 `first`가 유리합니다.

## 임시 라벨 표본 판정 (2026-11-03)
`det/second`의 임시 라벨 3,380개에서 무작위로 뽑은 100개를 사용자가 판정했습니다 (`labels/review_pseudo_sample_r1.json`).

| 판정 | 개수 | 반영 |
|---|---:|---|
| 봉오리 | 94 | 라벨 추가 (`source=review`, `ann_id=P...`) |
| 알수없음 (흐린 작은 꽃) | 3 | 제외 영역 |
| 봉오리 일부 (사진 가장자리 잘림) | 2 | 제외 영역 |
| 잎 | 1 | `labels/pseudo_rejected.csv` |

- **꽃이나 봉오리인 비율:** 96% (95% 구간 90.2~98.4%). 온전한 봉오리만 세면 94% (87.5~97.2%)입니다.
- **작은 박스:** 알수없음 3개는 모두 긴 변 40px 미만입니다. 표본에서 40px 미만은 6개뿐이라 비율을 따로 추정하지는 않습니다.
- **전부 봉오리인 이유:** 표본은 기존 라벨과 겹치는 예측을 뺀 것이고, 기존 라벨은 꽃잎 색이 보이는 후보를 잡은 것입니다. 이 설명은 추정이며 후보 전체의 단계를 세어 보지는 않았습니다. 표본이 모두 봉오리라 개화중, 만개 학습에는 도움이 된다고 볼 수 없습니다.
- 표본은 정밀도만 측정합니다. 임시 라벨이 놓친 꽃은 알 수 없습니다.

## 임시 라벨 2회차를 채택하지 않음 (2026-11-03)
`third_pseudo`의 예측으로 임시 라벨을 다시 만들어 학습한 `det/fourth_pseudo`는 val과 test 모두 `third_pseudo`보다 낮습니다. 임계값 0.55~0.75에서 test F1이 0.77을 넘지 않습니다. IoU 0.5와 0.3의 맞은 개수 차이가 26개에서 60개로 늘어 박스 위치도 나빠졌습니다. 원인은 분석하지 않았습니다. 2회차 임시 라벨은 사람이 보지 않았고 쓰지 않습니다 (`data_pseudo_r2/`, `runs/det/third_pseudo/cand/`).
