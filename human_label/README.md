# 사람 판정 파일

팀원이 브라우저로 여는 판정 파일과 받은 결과를 회차별로 둡니다. 회차마다 구성이 같습니다.

| 폴더 | 내용 | 상태 |
|---|---|---|
| `c1_initial/` | 초기 버전. 후보 1,713칸을 사진 단위로 5명에게 나누고 200칸만 두 명이 봄 | 팀원 판정 진행 중 |
| `c2_cross/` | 개선안. c1에서 한 명만 본 1,513칸을 다른 한 사람에게 더 줌 | 만들어 둠, 배포 전 |

- **`html/`:** 사람별 판정 파일. 농장 사진 조각이 들어 있어 git에 넣지 않고 팀 밖으로 공유하지 않습니다.
- **`labels/`:** 받은 결과 JSON을 넣는 곳입니다. 지금은 비어 있습니다.
- **번호표:** 번호와 사진, 기준 칸의 관계는 `../v1_box/labels/team_check_c1.csv`, `team_check_c2.csv`에만 있습니다. 팀원에게 주지 않습니다.

## 진행 순서
1. 팀원이 `c1_initial/html`의 자기 파일을 끝내고 JSON을 보냅니다. 받은 JSON은 `c1_initial/labels`에 넣습니다.
2. 같은 사람에게 `c2_cross/html`의 같은 글자 파일을 보냅니다. 받은 JSON은 `c2_cross/labels`에 넣습니다.
3. 두 회차를 합쳐 일치도와 불일치 칸을 뽑고, 불일치 칸은 사용자가 판단한 뒤 라벨에 반영합니다.

## c2 구성
| 항목 | 값 |
|---|---|
| 판정 인원 | 후보 1,713칸 모두 2명, 같은 사람이 두 번 보는 칸 없음 |
| 겹침 | 10개 짝 모두 170~172칸 |
| 사람별 합계 (c1 + c2 후보 칸) | 684~686칸 |
| 사람별 c2 칸 | A 325, B 296, C 295, D 329, E 314 (기준 칸 포함) |
| 예시 | c1과 같음 |

## 다시 만들기
```bash
cd v1_box
python scripts/61_make_team_cross.py c2 --base c1 --out ../human_label/c2_cross/html
python scripts/60_collect_team_check.py c1 --dir ../human_label/c1_initial/labels
```
`60_collect_team_check.py`는 회차를 하나씩 모읍니다. 두 회차를 합쳐 비교하는 스크립트는 결과를 받을 때 만듭니다. c2의 칸은 c1과 사진, 좌표가 같아 합칠 수 있습니다.
