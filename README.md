# 미니장미 꽃 모델
사진에서 꽃을 찾고 봉오리, 개화중, 만개를 판정하는 모델입니다. 큐브 안의 상태를 확인하는 것이 목적입니다. 잎 모델과 다른 모델이라 버전을 따로 셉니다.

## 버전
| 버전 | 구조 | 상태 |
|---|---|---|
| [v1_box](v1_box/README.md) ([리포트](v1_box/REPORT.md)) | 박스 탐지 + 박스별 단계 분류 | 현재 후보 `det/third_pseudo`, `cls/effnetv2s_r2` |
| v2_seg (예정) | 세그멘테이션 + ID + ID별 단계 분류 | 시작 전 |

점수는 모두 휴대폰 사진 기준입니다. 큐브 내부 ESP32 사진으로는 아직 평가하지 않았습니다.

## 폴더 규칙
- **리포트:** 중요 작업이 끝날 때 작성 여부를 사용자에게 먼저 묻고, 버전 폴더의 `REPORT.html`과 요약 `REPORT.md`에 씁니다.
- **`common/`:** 버전이 함께 쓰는 사진과 처음 라벨. `common/photos/`는 EXIF 위치 정보를 지운 사본입니다.
- **`vN_이름/`:** 버전마다 한 폴더. 이전 버전은 고치지 않습니다.
- **태그:** 잎 모델의 `v1`~`v10`과 겹치지 않게 `flower-vN`으로 답니다. 아직 단 태그는 없습니다.
- 잎과 함께 쓰는 사전학습 가중치는 저장소 루트의 `common/weights/`에 있습니다.
